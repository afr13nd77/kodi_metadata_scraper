# BL-70 — Язык имён актёров (ru / en)

## Статус: approved
## Версия: v3.19.0

---

## 1.1 Обзор

### Что строим и зачем?

Настройка выбора языка отображения имён актёров, режиссёров и сценаристов — русский или английский. Сейчас всегда используются русские имена (`nameRu` из KP API), что создаёт проблему при смешанных библиотеках: если часть фильмов добавлена через TMDb-based скрапер (где имена на английском), поиск по актёру в Kodi находит только часть фильмографии.

### Кто пользователь?

Пользователи Kodi с библиотеками, частично заполненными другими скраперами (TMDb, TVDB), а также пользователи, предпочитающие латинское написание имён.

### Какую проблему решаем?

Фрагментация фильмографии актёров в Kodi: «Brad Pitt» (от TMDb) и «Брэд Питт» (от UMS) — Kodi считает это разными людьми, фильмы не объединяются в одну карточку актёра.

## 1.2 User Stories

```
US-01: Как пользователь со смешанной библиотекой (UMS + TMDb),
       я хочу переключить язык имён на английский,
       чтобы поиск по актёру показывал все фильмы из библиотеки.

US-02: Как пользователь с чисто русской библиотекой,
       я хочу чтобы после обновления скрапера имена остались на русском по умолчанию,
       чтобы ничего не сломалось.

US-03: Как пользователь, выбравший английский язык имён,
       я хочу чтобы при отсутствии английского имени у актёра использовалось русское,
       чтобы имя не было пустым.
```

---

## 1.3 User Flows

```
FLOW-01: Пользователь переключает язык имён
1. Пользователь открывает Settings → Add-ons → metadata.ums → Configure
2. В секции «Метаданные» находит настройку «Язык имён (актёры, режиссёры)»
3. Выбирает «English» (по умолчанию — «Русский»)
4. Нажимает OK
5. Пересканирует библиотеку
   → Все имена актёров, режиссёров, сценаристов отображаются на английском
   → Если nameEn пустой у конкретного человека — используется nameRu
   → NFO-файлы (если включены) записываются с английскими именами

FLOW-02: Поведение по умолчанию (русский)
1. Пользователь устанавливает/обновляет скрапер
2. Настройка «Язык имён» = «Русский» по умолчанию
3. Сканирование библиотеки
   → Все имена на русском (текущее поведение, без изменений)
```

## 1.4 Acceptance Criteria

```
AC-01 (US-01):
  GIVEN: настройка actor_name_language = en
  WHEN: скрапер обрабатывает фильм/сериал с актёрами
  THEN: xbmc.Actor() получает name_en (если непустой) или name_ru (fallback)
        AND setDirectors() получает список name_en (или name_ru fallback)
        AND setWriters() получает список name_en (или name_ru fallback)

AC-02 (US-02):
  GIVEN: настройка actor_name_language = ru (по умолчанию)
  WHEN: скрапер обрабатывает фильм/сериал
  THEN: поведение идентично текущему — все имена на русском
        AND никаких изменений в вывод для пользователей, не менявших настройки

AC-03 (US-03):
  GIVEN: настройка actor_name_language = en
    AND актёр имеет nameEn = "" (пустой) и nameRu = "Иван Иванов"
  WHEN: скрапер передаёт имя в Kodi
  THEN: используется "Иван Иванов" (fallback на name_ru)
        AND в лог записывается предупреждение о пустом name_en

AC-04 (US-01):
  GIVEN: настройка actor_name_language = en
    AND enable_nfo_export = true
  WHEN: скрапер записывает NFO-файл
  THEN: элементы <name>, <director>, <credits> содержат английские имена
        (с тем же fallback на русские при пустых)

AC-05 (US-01):
  GIVEN: настройка actor_name_language = en
  WHEN: скрапер обрабатывает ТВ-сериал
  THEN: поведение идентично AC-01 — имена на английском в getdetails

AC-06 (US-02):
  GIVEN: настройка actor_name_language отсутствует (первая установка)
  WHEN: скрапер запускается
  THEN: по умолчанию используется "ru" — русские имена
```

## 1.5 Out of Scope

- Смешанный режим (часть имён на русском, часть на английском) — не реализуем.
- Автоопределение языка на основе TMDb-совместимости — слишком сложно.
- Отдельные настройки для актёров, режиссёров и сценаристов — одна настройка на всех.
- Изменение логики `parse_staff()` в `kinopoisk_api.py` — `name_ru` и `name_en` заполняются как сейчас, выбор происходит на этапе вывода.
- NFO-парсинг (чтение) — при чтении NFO имя всегда попадает в `name_ru`, это корректно: NFO содержит имя на том языке, на котором его записали.

---

## 1.6 Зависимости

- **KP API `/v1/staff`** — поле `nameEn` уже возвращается и парсится в `Person.name_en`.
- **Модель `Person`** — уже содержит оба поля (`name_ru`, `name_en`). Изменения модели не требуются.
- **`SettingsManager`** — нужен новый property для чтения настройки.
- **`settings.xml`** (оба аддона) — нужна новая настройка в секции «Метаданные».
