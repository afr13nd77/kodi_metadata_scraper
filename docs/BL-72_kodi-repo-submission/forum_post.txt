[B][SIZE=5]Ultimate Movie Scraper (UMS) v3.24.0[/SIZE][/B]
[i]Kinopoisk-based metadata scraper for movies and TV shows[/i]

UMS is a pair of fully independent Python scrapers for Kodi that provide Russian-language metadata from the Kinopoisk database. If your media library is primarily Russian-language content — or you simply prefer Russian titles, cast names, and descriptions — this scraper is built for you. It also pulls ratings from IMDB, Rotten Tomatoes, and Metacritic via OMDb, episode data from TVMaze, and additional artwork from FanArt.tv. TMDb is [b]not[/b] used.

[b]Platform:[/b] Kodi v20 Nexus / v21 Omega
[b]Language:[/b] Python 3.8
[b]License:[/b] MIT
[hr]

[B][SIZE=4]Features[/SIZE][/B]

[b]Movie Scraper ([font=Courier New]metadata.ums[/font])[/b]
[list]
[*]Search by Russian and English title with fuzzy matching and 3-level sorting (year, match score, rating)
[*]Full metadata: title, year, plot, genres, countries, studios, duration, MPAA rating
[*]Cast and crew with Russian names and photos (configurable: Russian or English names)
[*]Ratings: Kinopoisk, IMDB, Rotten Tomatoes, Metacritic — stored in Kodi rating DB
[*]Movie collections and franchises (auto-detected via Kinopoisk sequels API)
[*]Award tags: Oscar, Emmy, BAFTA, Cannes, Golden Globe
[*]FanArt.tv artwork: clearlogo, clearart, banner, landscape, discart
[*]Original language detection (country-to-ISO-639-1 mapping)
[*]YouTube trailers from Kinopoisk API
[*]NFO file support (read and auto-export)
[*]Persistent file cache (7-day TTL) with graceful degradation (stale cache and NFO fallback when API is down)
[*]Wikidata fallback for IMDB ID when Kinopoisk doesn't have it
[*]Duplicate Kinopoisk ID detection with toast notification
[*]Smart filename cleanup: release tags (BDRip, x265, 1080p, HDR, etc.) and collection prefixes (MCU150-, SW03-)
[/list]

[b]TV Show Scraper ([font=Courier New]metadata.tvshows.ums[/font])[/b]
[list]
[*]Search TV series (TV_SERIES, MINI_SERIES, TV_SHOW) with dual search (Russian + original title)
[*]Full series metadata with season and episode information
[*]Episode descriptions, directors, and writers from TVMaze (optional)
[*]Episode ratings from Kinopoisk + IMDB votes from OMDb
[*]TV show status (Returning Series / Ended / etc.) from TVMaze and Kinopoisk
[*]Season posters, season names, and episode thumbnails from TVMaze
[*]FanArt.tv artwork for shows and seasons: clearlogo, clearart, banner, landscape, characterart
[*]Smart filename parsing: S01E02, 1x02, Cyrillic patterns, anime absolute numbering
[*]TMDb/TVDB compatibility: auto-resolve Kinopoisk ID when migrating from another scraper
[*]Same caching, graceful degradation, NFO support, and Wikidata fallback as the movie scraper
[/list]

[b]Both addons are fully independent[/b] — install either or both, no cross-dependencies. Each has its own settings panel and API key configuration.

[B][SIZE=4]Installation[/SIZE][/B]

[b]Requirements:[/b] Kodi v20 Nexus or v21 Omega.
 
[list=1]
[*]Download the ZIP archive(s) from the [url=https://github.com/afr13nd77/kodi_metadata_scraper/releases]GitHub Releases[/url] page.
[*]In Kodi, go to [b]Settings > Add-ons > Install from zip file[/b].
[*]Select the ZIP you downloaded:
  - [font=Courier New]metadata.ums-3.24.0.zip[/font] — movie scraper
  - [font=Courier New]metadata.tvshows.ums-3.24.0.zip[/font] — TV show scraper
[*]Open the addon settings and enter your Kinopoisk API key.
[*]Set the scraper as your metadata provider: [b]Settings > Media > Movies (or TV Shows) > Information > Change content[/b], then select "Ultimate Movie Scraper" (or "Universal TV Show Scraper").
[/list]

[b]Getting API Keys[/b]
[list]
[*][b]Kinopoisk Unofficial API[/b] (required): Register at [url=https://kinopoiskapiunofficial.tech]kinopoiskapiunofficial.tech[/url] for a free key. Rate limit: 500 requests/day on the free tier.
[*][b]OMDb API[/b] (optional): Register at [url=https://www.omdbapi.com]omdbapi.com[/url] for IMDB, Rotten Tomatoes, and Metacritic ratings. May require VPN in some regions.
[*][b]FanArt.tv[/b] (optional): Register at [url=https://fanart.tv]fanart.tv[/url] for additional artwork (clearlogo, banner, etc.).
[/list]

[B][SIZE=4]Key Settings[/SIZE][/B]

Each addon has its own independent settings panel.

[TABLE]
[TR][TH]Setting[/TH][TH]Description[/TH][/TR]
[TR][TD]Kinopoisk API Key[/TD][TD]Required. Get it from kinopoiskapiunofficial.tech.[/TD][/TR]
[TR][TD]OMDb API Key[/TD][TD]Optional. Enables IMDB/RT/Metacritic ratings.[/TD][/TR]
[TR][TD]FanArt.tv API Key[/TD][TD]Optional. Enables additional artwork types.[/TD][/TR]
[TR][TD]Preferred rating[/TD][TD]Default rating source: Kinopoisk or IMDB.[/TD][/TR]
[TR][TD]Cast name language[/TD][TD]Russian or English names for actors and crew.[/TD][/TR]
[TR][TD]Genre language[/TD][TD]Russian or English genre names.[/TD][/TR]
[TR][TD]Use TVMaze[/TD][TD]Fetch episode descriptions from TVMaze (TV scraper only, off by default).[/TD][/TR]
[TR][TD]Use FanArt.tv[/TD][TD]Fetch additional artwork (off by default).[/TD][/TR]
[TR][TD]NFO export[/TD][TD]Auto-write .nfo files next to video files after scraping (off by default).[/TD][/TR]
[TR][TD]Duplicate detection[/TD][TD]Warn when the same Kinopoisk ID is assigned to different files.[/TD][/TR]
[TR][TD]Wikidata fallback[/TD][TD]Resolve IMDB ID via Wikidata when Kinopoisk doesn't have it.[/TD][/TR]
[TR][TD]Debug logging[/TD][TD]Verbose logging for troubleshooting.[/TD][/TR]
[/TABLE]

[B][SIZE=4]Known Limitations[/SIZE][/B]
 
[list]
[*]Kinopoisk Unofficial API requires a free API key (register at kinopoiskapiunofficial.tech). The free tier has a 500 requests/day limit — enough for most personal libraries, but very large initial scans may hit it.
[*]OMDb API may require a VPN in some regions.
[*]TVMaze episode descriptions are in English only.
[*]The scraper is primarily designed for Russian-language metadata. English metadata is available as a secondary option (cast names, genres).
[/list]
